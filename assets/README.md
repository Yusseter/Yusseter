# Assets

This directory contains the visual assets used by the Yusseter profile.

## Structure

- `logos/`: canonical logo SVG sources and generated PNG exports.
- `backgrounds/`: canonical background SVG sources and generated PNG exports.
- `profile/header/`: desktop and mobile profile header assets.
- `profile/icons/`: static profile UI icons.
- `profile/generated/languages/`: generated Seti language icons,
  grouped by theme and viewport.
- `profile/generated/snapshot/`: generated profile snapshot assets and
  alternate snapshot renderer assets.

Generated profile assets are written by `scripts/update_profile.py` and
should not be edited manually.

SVG files under `logos/` and `backgrounds/` are canonical sources. Their
PNG exports are generated by `scripts/update_visual_assets.py`.

## Naming

Underscores separate words within the same asset name:

`hittite_sun_disk_golden_crescent.svg`

Hyphens separate variants when the variant is part of the filename:

`hittite_sun_disk_golden_crescent-reversed.svg`

Structural variants such as theme, viewport, and generated output type use
directories when that produces a clearer hierarchy:

`profile/generated/languages/light/mobile/python.svg`

Generated files should not be edited manually.
