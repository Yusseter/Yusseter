# Logos

This directory contains the Hittite Sun Disk and Golden Crescent emblem.

## Variants

- `hittite_sun_disk_golden_crescent.svg`: Primary logo.
- `hittite_sun_disk_golden_crescent-reversed.svg`: Reversed plum variant.

The SVG files are the canonical sources.

## PNG Exports

PNG files are generated with `scripts/update_visual_assets.py` at:

- 256x256
- 512x512
- 1024x1024

Generated filenames include the variant, when applicable, followed by the output resolution:

`hittite_sun_disk_golden_crescent-512x512.png`

`hittite_sun_disk_golden_crescent-reversed-512x512.png`

Generated PNG files should not be edited manually.
